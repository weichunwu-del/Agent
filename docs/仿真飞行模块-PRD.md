# 仿真飞行模块 PRD

| 项 | 内容 |
|---|---|
| 产品 | 无人机航线作业平台 |
| 模块 | 仿真飞行（前置校验 / 回放评估） |
| 版本 | V1.0 |
| 状态 | 需求冻结（设计评审已纳入） |
| 关联设计 | `design/simulation-flight.html`（1920×1080 高保真稿） |
| 上游页面 | 航线编辑器 |
| 下游动作 | 返回手动改线 / AI 一键优化后回写航线 |

---

## 1. 背景与问题

航线编辑器已能把航点、航线画在地图上，但「画出来」不等于「飞得成、到得了、巡得有效」。碰撞、贴障、禁飞、续航不够、巡检区域没覆盖、画面不满足算法等问题，往往要到实飞才暴露，改线成本高、安全风险大。

本模块在任务下达、实飞之前，用仿真把航线跑一遍，把隐患前置到编辑阶段处理。

要回答的不是「航线长什么样」，而是：

1. 全程飞得安不安全  
2. 航线上每个点人机都到得到吗  
3. 这趟巡检完整有效吗  

---

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标 |
|---|---|
| G1 | 实飞前完成航线仿真，输出安全性、可达性、有效性三类结论 |
| G2 | 仿真过程可回放、可对照 FPV 与第三视角，风险可定位到航点/航段 |
| G3 | 有风险时，用户只能选择「返回手动修改」或「AI 一键优化」，不能带风险直接执行 |
| G4 | 评估用语对作业人员直白，与分析模型一一对应，不发明第三套口径 |

### 2.2 非目标（本期不做）

- 不替代实飞飞控、不直接对飞机下发航线
- 不做仿真报告导出
- 不在本页展示环境气象（风、温度、能见度）
- 不在设备信息中展示相机、云台型号（云台俯仰角只作为 FPV 飞行叠加）
- 不提供「忽略风险继续使用」「重新仿真」作为评估结论出口（回放条上的暂停/重飞不属于评估决策）

## 3. 用户与场景

| 角色 | 诉求 |
|---|---|
| 航线规划员 | 编完航线后先仿真，看这条线能不能拿去飞 |
| 巡检作业员 | 看隐患出在哪一段、改完能否覆盖任务区域、画面能不能给算法用 |
| 审核/值班 | 看评估结论，决定回改还是让 AI 出一版可执行航线 |

**主路径**

航线编辑完成 → 进入仿真飞行 → 回放并查看实时分析 → 仿真结束出评估 → 有风险则手动改线或 AI 优化 → 优化/修改后可再次仿真 → 三维均通过后才允许进入实飞流程。

**示例任务（设计稿演示数据，非唯一业务）**

- 任务：绕城高速 K1–K4 巡检  
- 内容：车辆故障、行人闯入  
- 机型：多旋翼-EVO  
- 规划高度 80 m、速度 12 m/s、航点 32、航线 10.2 km、时长 08:45

## 4. 术语

| 术语 | 含义 |
|---|---|
| 仿真飞行 | 按规划航线、机型包线与环境约束，在数字场景中预演飞行与巡检 |
| 航点 | 规划轨迹上的位置点（含高度、速度等参数） |
| 航段 | 相邻航点之间的飞行区间 |
| 对地线 | 第三视角中，空中航点到其正下方地面投影的竖向参考线 |
| 实时分析 | 仿真过程中按三维模型滚动产出的风险/通过项 |
| 仿真评估 | 仿真结束后的维度评分 + 文字结论 + 决策按钮 |
| 安全性 | 全程安全飞行（见第 7 章） |
| 可达性 | 无人机能够到达航线上任意点（见第 7 章） |
| 有效性 | 完整有效巡检（见第 7 章） |

界面展示名与分析模型名必须同时出现或可互相解释，避免「可飞性」等易被理解成性能术语的叫法。推荐展示：

| 分析维度（系统名） | 界面主名 | 界面释义 |
|---|---|---|
| 安全性 | 全程安全 | 从起飞到降落，会不会撞、会不会贴太近、高度速度过不过线 |
| 可达性 | 航点都能到 | 电够不够飞完这条线，有没有被禁飞/限制空域挡住 |
| 有效性 | 巡检完整有效 | 该巡的区域巡全了没有，拍出来的画面算法认不认得 |

```
[航线编辑器] --开始仿真--> [仿真飞行页]
                               | 回放中：FPV / 第三视角 / 实时分析
                               v
                         [仿真评估]
                    ┌──────────┴──────────┐
                    │                     │
              三维均通过              存在风险
                    │                     │
              允许进入实飞         仅两个出口：
                                  1. 返回手动修改 → 航线编辑器
                                  2. AI 一键优化 → 生成新航线 → 可再次仿真
```

有风险时禁止：忽略风险继续使用、直接下发实飞、把「重新仿真」当作评估结论按钮。

## 7. 仿真分析模型（核心）

分析只分三维。实时分析列表是三维的过程展开，评估卡片是三维的结果汇总。口径必须一致。

### 7.1 安全性 — 全程安全飞行

评的是**飞行过程本身安不安全**，不是续航、不是巡检拍得清不清。

| 子项 | 判定内容 | 不通过时的业务表现 |
|---|---|---|
| 起降场安全 | 进场、离场通道是否安全 | 起降阶段贴障、通道不可用 |
| 航线安全 | 航迹是否与地形、桥梁、构筑物碰撞 | 刮擦、撞击 |
| 安全距离 | 与障碍物、结构物是否保持安全间隔 | 过近、无缓冲 |
| 飞行参数约束 | 高度、速度是否落在机型与任务约束内 | 超高、超速、低于允许高度 |

### 7.2 可达性 — 无人机能够到达航线上任意点

评的是**规划航线上每一个点，这架飞机物理上到得到**，不是「巡检对象在不在画面里」。

| 子项 | 判定内容 | 不通过时的业务表现 |
|---|---|---|
| 航程覆盖 | 任务能耗 + 返航 + 预留电量是否覆盖整条航线 | 中途电量不足、飞不完 |
| 空域可达 | 航迹是否进入禁飞区、限制空域，或无法合法穿越 | 被空域挡住、到不了后续航点 |

### 7.3 有效性 — 完整有效巡检

评的是**这趟飞对巡检任务有没有用**：区域有没有巡全，采集画面能不能给算法用。

| 子项 | 判定内容 | 不通过时的业务表现 |
|---|---|---|
| 区域覆盖 | 航线是否覆盖任务目标区域 | 漏段、漏点、任务范围没飞到 |
| 视场效果 | 相机视场、高度、姿态是否满足识别算法采集要求 | 飞得太高/太偏，目标不稳定检出 |

三维互不替代：

- 全程安全但电不够 → 安全性过、可达性不过  
- 航点都能到但没覆盖任务区域 / FOV 不够 → 可达性过、有效性不过  
- 区域覆盖了但贴桥过近 → 有效性可能过、安全性不过

## 8. 功能需求

### 8.1 顶栏

| 字段 | 规则 |
|---|---|
| 标题 | `仿真飞行 · {任务名称}` |
| 状态 | 仿真进行中 / 仿真回放中 / 仿真已完成 |
| 任务编号 | 展示仿真任务 ID |

可提供返回航线编辑器入口；与评估区「返回手动修改」同一去向，评估完成且有风险时以评估区主按钮为准。

### 8.2 基本信息（左栏）

只保留三块。

**任务**

- 任务区域  
- 任务内容  

**设备**

- 机型名称、机型图片、类型标签（如「巡检机型」）  
- 本航线规划飞行高度  
- 本航线规划飞行速度  
- **不展示**相机、云台产品信息  

**航线信息**

- 航点数量  
- 航线长度  
- 预计时长  

**不展示**环境信息模块（气象、风速等）。

### 8.3 仿真视窗（中栏）

#### 8.3.1 FPV（上窗）

第一人称巡检画面，叠加仅保留作业需要的飞行参数。

| 叠加 | 位置 | 规格 |
|---|---|---|
| 实时高度、实时速度 | 左上 | 半透明数字条，高度 + 速度并排，如 `80 m` \| `12.0 m/s` |
| 偏航角罗盘 | 左下 | 航向罗盘：刻度环随偏航转动，正上方绿色数字为当前偏航角，中央为机头指向，左右红标、顶部绿准星 |
| 云台俯仰角 | 罗盘右侧 | 垂直标尺，中间高亮刻度 + 数值徽章（如 `-10°`） |

**禁止叠加：** 信号、电量、设置；H / D / HS / VS；ISO / EV；FPV / 第三视角切换 Tab。

#### 8.3.2 第三视角（下窗）

数字孪生/三维地图，用于看航线空间关系。

必须满足：

1. 航线画在空中，不贴地  
2. 每个航点到正下方地面投影有对地线  
3. 无人机模型贴在航线上，不悬在航线上方  
4. 已飞 / 当前 / 未飞航段样式可区分  
5. 风险点打在对应航点或航段上，与右侧事件、时间轴标记同一编号  

工具栏仅保留必要操作（如 3D、回中、图层），去掉最下方定位类多余图标。

窗角可保留视角说明（如「第三视角 · 数字孪生」）和相对高度。

#### 8.3.3 回放条

- 暂停 / 继续  
- 重新飞行（从起点重放，不是评估结论里的「重新仿真」出口）  
- 倍速：1x / 2x / 4x  
- 进度条；风险编号打在对应进度位置  
- 已飞里程 / 总里程、剩余时长  

**无「导出报告」。**

### 8.4 实时分析（右栏）

标题：实时分析。展示仿真过程中已识别项（通过或风险）。

每条至少包含：

| 字段 | 说明 |
|---|---|
| 编号 | 与地图、时间轴一致，如 01 |
| 名称 | 业务短名，如 碰撞风险、空域风险、检测质量不足 |
| 所属维度 | 安全性 / 可达性 / 有效性 |
| 等级 | 高 / 中 / 低（或通过） |
| 说明 | 人话，说明发生了什么、为何构成风险 |
| 位置 | 航点或航段 + 业务里程（如 K1+820） |

点击条目：第三视角飞到对应位置，回放跳到对应时刻，FPV 切到该时刻画面。

示例（演示任务，用于设计对齐，规则以第 7 章为准）：

| 编号 | 维度 | 名称 | 等级 | 要点 |
|---|---|---|---|---|
| 01 | 安全性 | 碰撞风险 | 高 | 近桥过近，刮擦/撞击 |
| 02 | 可达性 | 空域风险 | 高 | 航段进入限制空域，后续航点不可达 |
| 03 | 有效性 | 检测质量不足 | 中 | 高度偏高，视场不满足算法检出 |

### 8.5 仿真评估（底栏）

模块标题：**仿真评估**（不用「仿真评估结论」）。

只分两块。

#### 8.5.1 维度评分

三张卡，顺序固定：

1. 全程安全（安全性）  
2. 航点都能到（可达性）  
3. 巡检完整有效（有效性）  

每张卡：主名、一句释义、星级、分数（0–5，一位小数）。

状态区展示 **飞行时长**（不用「完成时间」），以及「仿真已完成」等状态。

#### 8.5.2 评估结论

- 用三维口径写人话结论，点明哪一段、哪一类问题  
- 有任一高/中风险：**存在风险，不建议直接执行**  
- 三维均通过：**可以进入实飞流程**（实飞入口不在本页强行放置，由平台后续流程承接）  

**有风险时，用户可选操作有且仅有：**

| 按钮 | 样式 | 行为 |
|---|---|---|
| 返回手动修改 | 描边次按钮 | 回到航线编辑器，定位到问题航段 |
| AI 一键优化 | 主按钮 | 按已识别风险自动改线，生成可再次仿真的方案 |

禁止再放：忽略风险继续使用、重新仿真（评估出口）、导出报告。

无风险时：不展示 AI 一键优化；可仅保留返回编辑器查看/微调。

## 9. AI 一键优化

**何时可用：** 仿真已完成，且存在未关闭风险。

**价值：** 按已识别问题改线，减少人工反复试。

**改线原则（与三维对应）：**

| 风险类型 | 优化动作（示例） |
|---|---|
| 安全性：近障/碰撞/距离不足 | 抬升或外扩问题航段，恢复安全间隔 |
| 可达性：限制空域 | 绕开禁飞/限制区，保证后续航点仍可达 |
| 可达性：航程不足 | 缩航、降速或调整剖面，使续航覆盖全程+返航+预留 |
| 有效性：区域未覆盖 | 补点或调整航迹，覆盖任务区域 |
| 有效性：视场不满足算法 | 下调巡检高度或调整姿态，使 FOV 满足采集要求 |

优化结果必须回写成可编辑航线，并提示用户**再次仿真**后才能进入实飞。优化失败则保留原航线，提示失败原因，仍可返回手动修改。

## 10. 评分与结论规则

### 10.1 子项到维度

每个子项：通过 / 低风险 / 中风险 / 高风险。  
维度分由该维子项最差等级约束，再按问题航段占比微调（实现可迭代，产品口径如下）：

| 该维最差等级 | 分数区间 | 星级参考 |
|---|---|---|
| 全部通过 | 4.6 – 5.0 | 5 |
| 仅低风险 | 4.0 – 4.5 | 4 |
| 存在中风险、无高风险 | 3.0 – 3.9 | 3 |
| 存在高风险 | 0 – 2.9 | 1–2 |

演示数据对齐：全程安全 4.5、航点都能到 4.0、巡检完整有效 3.0。

### 10.2 总结论

| 条件 | 结论 |
|---|---|
| 三维均 ≥ 4.0 且无高风险 | 可以进入实飞流程 |
| 存在中风险、无高风险 | 存在风险，建议优化后再执行 |
| 存在高风险 | 存在风险，不建议直接执行 |

## 13. 验收标准

1. 从航线编辑器能进入仿真飞行页，任务名、机型、航点、里程、时长与编辑结果一致。  
2. FPV 与第三视角上下排布，无视角 Tab；FPV 可见高度、速度、偏航角、云台俯仰角，无信号/电量/H/D/ISO 等已禁叠加。  
3. 第三视角航线在空中，航点有对地线，飞机在航线上。  
4. 回放可暂停、重飞、倍速；风险编号在地图、列表、时间轴三处一致，点击可跳转。  
5. 实时分析每条能归到安全性 / 可达性 / 有效性之一，子项不串维（禁飞不进安全性、碰撞不进可达性、漏覆盖/FOV 不进可达性）。  
6. 仿真结束后出现仿真评估；有风险时结论为不建议直接执行，按钮只有「返回手动修改」「AI 一键优化」。  
7. 返回手动修改回到编辑器并指向问题航段；AI 一键优化产出新航线且需再次仿真。  
8. 无导出报告；无忽略风险继续执行。
