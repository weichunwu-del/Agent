# 仿真飞行设计稿（修订）

高保真稿：`simulation-flight.html`  
效果图：`simulation-flight.png`（1920×1080）

本轮按评审意见调整 FPV 叠加与评估操作：

## FPV 视窗

- 圆形仪表盘改为偏航角罗盘：刻度环随航向转动，正上方绿色读出当前偏航角（126.9°），中央为机头指向
- 罗盘右侧增加云台俯仰角标尺，中间高亮刻度 + 数值徽章（-10°）
- 左上角增加实时高度 / 速度数字条：80 m、12.0 m/s

## 仿真评估

- 存在风险时，用户可选操作只保留两项：**返回手动修改**、**AI 一键优化**
- 去掉忽略风险、重新仿真等其它出口，避免带风险直接执行
