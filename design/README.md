# 仿真飞行设计稿（修订）

高保真稿：`simulation-flight.html`  
效果图：`simulation-flight.png`（1920×1080）

相对上一版，本轮按评审意见做了这些调整：

## 基本信息

- 设备模块只保留机型、飞行高度、飞行速度，去掉相机、云台
- 去掉环境信息模块

## 仿真视窗

- 上下双窗本身就是 FPV / 第三视角，去掉顶部切换 tab
- 去掉右上角信号、电量、设置，以及左下角 H/D/HS/VS、右下角 ISO/EV 等叠加
- 罗盘展示当前偏航角数值（YAW 042°）
- 第三视角航线抬到空中，每个航点用虚线对地线连到正下方地面投影
- 无人机贴在航线上，不再悬在航线上方
- 左侧工具栏去掉最下方定位图标
- 去掉「导出报告」

## 仿真评估

- 模块标题改为「仿真评估」
- 「完成时间」改为「飞行时长」
- 只保留两块：维度评分、评估结论
- 存在风险时给出 **AI 优化航线**：自动抬升近桥航段、绕开限制空域、下调巡检高度，减少人工反复改线

在浏览器打开 `simulation-flight.html` 即可查看可缩放原稿。
