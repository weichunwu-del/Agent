# 航线仿真校验

无人机航点航线编辑界面的前置安全校验：在实飞前用仿真航迹把地形碰撞、禁飞区、电量与返航走廊等风险暴露出来。

## 为什么需要仿真

地图上的航点连线只能说明「飞机打算怎么飞」，不能回答「这样飞安不安全」。线性爬升会切脊线、返航高度可能低于沿途地形、航线可能擦过禁飞区——这些都要在任务下达前用同一套地形与机型包线算一遍。

本仓库把校验做成可回放的仿真：

1. 按机型速度 / 爬升率 / 功耗把航点展开成时间采样航迹
2. 在每个采样点上跑安全规则
3. 把命中点画回三维地图，并支持按风险条目跳转、变速回放、FPV 预览

默认演示航线会故意贴近一条林脊，用来对照「只看航点」和「仿真校验」的差别。点「应用抬升修订方案」可看到风险被消掉后的航迹。

## 校验规则

| 规则 | 说明 |
| --- | --- |
| 地形间隙 / 碰撞 | 航迹离地高度对照机型安全间隙 |
| 高度包线 | 相对高度与最大离地限制 |
| 禁飞 / 限飞 | 多边形穿透与 80 m 邻近缓冲 |
| 电量 | 任务能耗 + 返航 + 预留百分比 |
| 返航走廊 | 从航迹点以 RTH 高度飞回 Home 是否切地形 |
| 速度 / 爬升率 / 转弯 | 是否超出机型运动学包线 |
| 链路距离 | 遥控 / 图传参考半径 |

引擎与 UI 解耦，规则位于 `src/engine/`，可用 `npm test` 单独回归。

## 本地运行

```bash
npm install
npm test
npm run dev
```

浏览器打开提示的本地地址。空格播放 / 暂停，左右方向键步进。地图 WASD 平移，Q/E 旋转。单击地图添加航点。

## 技术栈

- Vite + React + TypeScript
- Cesium（Esri 影像 + 与校验共用的合成 DEM）
- Zustand
- Vitest（地理计算与安全规则）
